# 💰 MeDeve - Sistema de Controle Financeiro

<p align="center">
  Sistema desenvolvido em PHP para gerenciamento de contas a pagar e receber, com autenticação de usuários e painel administrativo.
</p>

---

## 📖 Sobre o Projeto

O **MeDeve** é um sistema web desenvolvido para auxiliar no controle financeiro de usuários, permitindo o gerenciamento de contas, visualização de informações e autenticação através de login.

O projeto foi desenvolvido utilizando PHP puro, HTML, CSS e Bootstrap, com foco em aprendizado e prática dos conceitos de desenvolvimento web.

---

## 🚀 Funcionalidades

✅ Sistema de Login

✅ Controle de Sessão

✅ Dashboard do Usuário

✅ Cadastro de Contas

✅ Edição de Contas

✅ Exclusão de Contas

✅ Listagem de Contas

✅ Controle de Perfis de Usuário

✅ Interface Responsiva com Bootstrap

## ⚙️ Como Executar

### 1️⃣ Clone o repositório

```bash
git clone https://github.com/SEU-USUARIO/SEU-REPOSITORIO.git
```

### 2️⃣ Abra o projeto

Coloque a pasta do projeto dentro do diretório do seu servidor local:

- XAMPP → `htdocs`
- WAMP → `www`

### 3️⃣ Inicie o servidor

Abra o Apache pelo XAMPP ou WAMP.

### 4️⃣ Execute o sistema

Acesse:

```text
http://localhost/Sistema_MeDeve
```
